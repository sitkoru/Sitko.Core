# Конфигурация из Vault

[English](../en/vault.md) · [Все темы](README.md)

`Sitko.Core.Configuration.Vault` читает KV v2 через VaultSharp и добавляет значения
в конфигурацию .NET. Нужны доступный сервер, существующий mount KV v2 и права чтения
секретов и перечисления путей для используемого дерева. После `AddSitkoCore()`
подключите `AddVaultConfiguration()` из пространства имён пакета.

Секция `Vault`:

| Параметр | Назначение и значение по умолчанию |
| --- | --- |
| `Uri` | Адрес Vault; обязателен. |
| `MountPoint` | Mount KV v2, по умолчанию `secret`. |
| `Secrets` | Пути секретов/деревьев; при пустом списке используется имя приложения. |
| `AuthType` | `Token` по умолчанию; альтернатива `RoleApp`. |
| `Token` | Обязателен для `Token`. |
| `VaultRoleId`, `VaultSecret` | Обязательны для `RoleApp` (AppRole). |
| `ReloadOnChange`, `ReloadCheckIntervalSeconds` | Опрос обновлений включён, интервал 60 секунд. |
| `RenewToken`, `TokenRenewIntervalMinutes` | Продление Token включено, интервал 60 минут. |
| `ThrowOnEmptySecrets` | `true`: проверка при запуске отвергает пустые источники. |
| `OmitVaultKeyName` | `false`: сохраняет имя ключа в пути конфигурации. |

Например, для отдельного стенда задайте `Vault__Uri`, `Vault__MountPoint`,
`Vault__Secrets__0` и `Vault__Token` средствами окружения, затем проверьте ожидаемое
значение через `IConfiguration` без вывода секрета в журнал. Провайдер преобразует
вложенные JSON-объекты и массивы в пути .NET; `/` в относительном пути заменяется `:`.
`AdditionalCharactersForConfigurationPath` позволяет задать дополнительные заменяемые символы.

Перечитывание конфигурации не означает, что каждый потребитель перестраивает свои
подключения. При ошибке HTTP/Vault загрузчик может сохранить последние значения;
после успешной авторизации отказ доступа сбрасывает токен. Первоначальный отказ
авторизации выбрасывается наружу. Не рассматривайте модуль как гарантию свежести
секретов или отказоустойчивый резервный источник; отдельно проверьте свои сценарии
смены секрета и отказа. `ThrowOnEmptySecrets` проверяет пустоту, а не полноту схемы приложения.
