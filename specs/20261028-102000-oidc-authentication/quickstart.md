# Проверка результата

.NET SDK 10.0.403; запуск из корня дерева задачи. Изолированные проверки Auth выполняются
через dotnet test с фильтром, исключающим RedisAuthTests/RedisClusterTests. Полный Auth
набор требует отдельных Valkey-стендов из tests/Sitko.Core.Auth.Tests/Valkey.
Не запускать проверки отказа primary против общего localhost. CI создаёт собственные
стенды. Реальная приёмка Keycloak описывается в инструкции потребителей и остаётся
отдельной: разрешённый/запрещённый пользователь, SSO, внешний вход, выход, отзыв роли.
