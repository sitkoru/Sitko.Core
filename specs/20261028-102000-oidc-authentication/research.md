# Исследование

- Решение: штатные ASP.NET handlers; собственный адаптер Keycloak не требуется.
- Основание: текущий модуль использует AddOpenIdConnect/AddJwtBearer, Keycloak поддерживает OIDC discovery/code/refresh/revocation/logout.
- Duende 4.3.0 подтверждён NuGet; пакет для net10 требует OIDC >=10.0.13, база уже 10.0.14.
- Привязка к IdentityServer4 — неиспользуемый специализированный пакет с транзитивным JwtBearer 3.0.0; заменить прямой актуальной зависимостью.
- Альтернатива нового менеджера токенов отклонена: уже используется Duende и собственные хранилища с необходимыми свойствами.
- Точное API Duende и совместимость сериализации проверяются по пакету 4.3.0 и исходному commit из nuspec.
- Допуск пользователей — роль клиента Keycloak; библиотека не дублирует список email.
