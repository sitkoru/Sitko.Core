# Проверка качества требований SD/gRPC

**Спецификация**: [spec.md](../spec.md). **Обновлено**: 2026-10-28.

Чеклист оценивает документационную подготовку. Отметки не означают выполненные тесты или готовую реализацию.

## Содержание и полнота

- [x] Требования описывают наблюдаемое поведение, ограничения и действия потребителей.
- [x] Microsoft SD, Consul DNS SRV, полное protobuf-имя и TLS — согласованные требования; альтернативы и причины необходимой переработки приведены в `plan.md`/`research.md`.
- [x] Сохранены исходные ссылки и ревизии; состояние v12 отделено от целевой схемы и свежей платформы v13.
- [x] Общие/индивидуальные настройки, порядок обработчиков настроек, единый клиент, fluent-сервер и optional SD согласованы между материалами.
- [x] Несовместимость и план миграции MYCG описаны без команды менять его код.
- [x] Только `net10.0`, принятые версии пакетов и runner; повторная миграция не планируется.
- [x] V01–V16 согласованы и имеют данные, ожидания, реальные компоненты, ограничения и матрицу требований/задач в [verification.md](../contracts/verification.md).
- [x] Проверка 256 МиБ и сравнение времени/памяти исключены; проверка лимитов использует 2 МиБ.
- [x] Собственная инфраструктура и запрет shared/чужих/production-ресурсов описаны явно.
- [x] Не осталось ожидания повторного согласования уже принятых сценариев.
