# Модель настроек

OpenTelemetryModuleOptions сохраняет существующие флаги, Uri? Endpoint и
OtlpExportProtocol. Headers — Dictionary<string,string>, пустой по умолчанию.
После привязки .NET и программной настройки выбираются общие непустые env
поля; словарь заголовков заменяется целиком. Внутренний результат содержит
проверенные базовый адрес, протокол и заголовки. Значения заголовков не входят
в сообщения об ошибках. Настройки неизменны для живущих экспортёров до restart.
