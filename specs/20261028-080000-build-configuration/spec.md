# Общая конфигурация сборки Sitko.Core

**Создано**: 2026-10-28  
**Статус**: реализовано  
**Основа требований**: R13 и согласованная поправка версии EF Design.

## Пользовательские сценарии и проверка

### US1 — Сопровождать общие настройки (P1)

Разработчик меняет общую настройку или версию в одном месте, сохраняя различия
между публикуемыми библиотеками, тестами, примерами и измерениями производительности.
Приоритет определяется подготовкой обновлений платформы и зависимостей R04/R05.

**Независимая проверка**: вычислить настройки каждого проекта для всех его платформ,
собрать решение и сравнить состав публикуемых пакетов с исходной версией.

1. Общие настройки применяются ко всем предназначенным для них проектам.
2. Тестовые ссылки, SourceLink и упаковка применяются только в своих областях.
3. Примеры и измерения производительности сохраняют свои целевые платформы и параметры.
4. PostgreSQL-тест использует общую версию EF Design по целевой платформе.

### Пограничные случаи

- Вложенный файл настроек явно подключает общий файл; совпадающие объявления не дублируются.
- Различающиеся версии по целевой платформе сохраняются.
- Метаданные пакетной ссылки и пути ресурсов не меняются при переносе версии.

## Требования

- **FR-001**: Общие настройки сборки и таблица версий находятся в корне репозитория.
- **FR-002**: Настройки платформы, языка, предупреждений, nullable, implicit usings,
  упаковки и ресурсов сохраняют эффективные значения для каждой области.
- **FR-003**: Перенос версий не добавляет пакетных ссылок и сохраняет их метаданные.
- **FR-004**: Версии сохраняются, кроме согласованного исправления EF Design
  PostgreSQL-теста: общая версия по TFM без локального переопределения.
- **FR-005**: Изменение не обновляет SDK/TFM, не перестраивает CI и не меняет публичный API.

## Критерии приёмки

- **SC-001**: Для всех сохраняемых проектов сравнение настроек не выявляет
  непредусмотренных различий; EF Design отдельно подтверждён для обеих платформ.
- **SC-002**: Решение собирается, состав публикуемых пакетов и метаданные сохраняются;
  новые предупреждения отсутствуют либо объяснены согласованной поправкой.
- **SC-003**: Существующие проверки подтверждают работу тестового запуска и примеров.

## Предпосылки

Удаление согласованных модулей R03 завершено. Обновления платформы и пакетов R04/R05
выполняются отдельными изменениями после R13.
