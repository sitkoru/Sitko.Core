# Спецификация: локальное gRPC-демо с обязательным Consul

Связь: [R10](../../ROADMAP.md#r10); поведение библиотек определено [контрактом gRPC/SD](../20261027-193928-service-discovery/spec.md).

## Пользовательский сценарий

Разработчик запускает отдельный локальный Consul, затем существующее приложение gRPC на .NET 10
по инструкции RU/EN. Запрос `/Test` вызывает настоящий `greet.FooService/Foo` через обнаружение
сервисов и возвращает точный ответ `Baz 123`. Сервер и клиент находятся в одном приложении;
это не демонстрация нескольких независимых экземпляров.

## Требования

- **FR-001**: Consul обязателен; прямой адрес клиента и запасной путь в обход обнаружения отсутствуют.
- **FR-002**: `/Test` выполняет реальный RPC с входным `Bar=123`, ожидаемый `Baz 123` задан контрактом примера.
- **FR-003**: TLS использует доверенный локальный сертификат; отключение проверки сертификата не применяется.
- **FR-004**: Consul имеет собственные локальные HTTP/DNS-порты, отдельный Compose-проект и явные команды остановки; чужие стенды не затрагиваются.
- **FR-005**: инструкции RU/EN описывают предпосылки, запуск, адреса, признак готовности и ожидаемый ответ.
- **FR-006**: сохраняются существующие приложение и protobuf-контракты, библиотеки не перерабатываются, Blazor не меняется.

## Приёмка

1. По инструкции запустить свой Consul и приложение без частной конфигурации; проверить опубликованные контракты и DNS SRV.
2. Получить `/Test` по TLS: HTTP 200 и точный `Baz 123`; журнал сервера подтверждает выполнение Foo RPC.
3. В конфигурации отсутствует прямой Address, стандартная проверка сертификата включена.
4. Без Consul при свежем процессе клиента успешного RPC нет; восстановить только собственный стенд для основной проверки.
5. Остановить созданные процессы и собственный Compose-проект; чужие ресурсы не менять.

## Границы

Только net10.0, без новых приложений/контрактов/произвольных автотестов, публикаций, тегов,
production и потребителей. Многорепличная устойчивость и производительность здесь не проверяются.
Новые границы автоматических тестов требуют согласования; основной результат проверяется настоящим локальным запуском.
