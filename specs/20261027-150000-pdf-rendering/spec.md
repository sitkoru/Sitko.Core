# Генерация PDF и снимков страниц

**Создано**: 2026-10-27  
**Статус**: реализовано

## Пользовательские сценарии и проверка

### US1 — Получить документ или снимок (P1)

Приложение регистрирует рендерер и получает PDF либо PNG из HTML или URL без отдельного модуля браузера. Проверка выполняется через регистрацию приложения и публичный рендерер.

1. Для фиксированного HTML и локальной страницы обе операции PDF возвращают документ с известным русским текстом.
2. Обе операции снимка возвращают PNG с ожидаемыми размерами; вся страница снимается по умолчанию.
3. Указанные размеры PDF и снимка соблюдаются; подключённые CSS и изображения загружаются с контролируемого HTTP-сервера.

### US2 — Выбрать окружение браузера (P1)

Приложение использует установленный локальный Chromium либо подключается к существующему Chromium. После завершения запроса следующая генерация работает; удалённый браузер остаётся доступным.

### Пограничные случаи

Ошибка рендера возвращается вызывающему коду с исходной причиной; принадлежащие запросу ресурсы освобождаются и при ошибке. Браузер устанавливается при подготовке окружения, а не при рендере.

## Требования

- **FR-001**: Сохранить четыре операции `IPdfRenderer` для PDF и снимков HTML/URL, возвращающие `byte[]`, и необязательную задержку `TimeSpan?` после загрузки.
- **FR-002**: При отсутствии параметров PDF печатает фон, снимок имеет формат PNG и охватывает всю страницу. Параметры вызова позволяют задать размеры результата.
- **FR-003**: Публичные параметры PDF и снимка используют `PagePdfOptions` и `PageScreenshotOptions` Microsoft.Playwright. Это согласованное несовместимое изменение API.
- **FR-004**: Для работы достаточно `AddPdfRenderer()`. Конфигурация `PdfRenderer` выбирает локальный Chromium либо `BrowserWsEndpoint` по CDP и позволяет настроить сертификаты, окно, аргументы и запуск без интерфейса.
- **FR-005**: Каждый запрос создаёт собственный изолированный контекст, освобождает его и локальный браузер либо удалённое соединение; чужой удалённый браузер не завершается.
- **FR-006**: Рендерер не скачивает браузер при вызове и не зависит от `Sitko.Core.Puppeteer`. Сам модуль Puppeteer остаётся доступным другим потребителям.
- **FR-007**: HTML и URL поддерживают CSS и изображения с доступного HTTP-сервера.

## Критерии успеха

- **SC-001**: Все четыре операции возвращают проверяемый результат для фиксированных локальных данных: русский текст PDF либо сигнатуру и размеры PNG.
- **SC-002**: Тот же набор проверок проходит с локальным и удалённым браузером; повторная генерация после очистки успешна.

## Допущения и границы

Chromium и системные зависимости подготовлены заранее; URL доступен со стороны выбранного браузера. Пулы, повторные попытки, изменение потребителей и эксплуатационных окружений не входят в изменение.
