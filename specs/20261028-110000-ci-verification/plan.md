## Уточнение после независимого ревью

Проверка Consul ожидает JSON с непустым адресом лидера: HTTP 200 с `""`
недостаточен. Воспроизведение на локальном HTTP-сервере сначала обнаружило
преждевременный успех, затем подтвердило переход `""` → адрес. Постоянно пустой
ответ и отказ соединения завершаются exit 124 по сокращённому контрольному сроку.
В workflow общий предел составляет 60 секунд, отдельный HTTP-запрос — 5 секунд.

В закреплённом SDK-образе непосредственно проверены `bash`, `curl`, `timeout`
и `sleep`; доступны Bash 5.2.21, curl 8.5.0 и GNU coreutils 9.4.
Выражение проверки отвергает пустого лидера и принимает адрес с портом также
в Bash этого образа. Проверки структуры CI, синтаксиса Bash и прежних
условий release/npm повторены. Контракт готовности и обычная документация
не менялись: исправлено несоответствие реализации существующему требованию.
